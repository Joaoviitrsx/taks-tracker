# Task Tracker CLI

Uma interface de linha de comando (CLI) simples e nativa em Node.js para gerenciar tarefas locais.

## Pré-requisitos
- [Node.js](https://nodejs.org/) v18 ou superior instalado (sem bibliotecas externas).

## Como Executar

Não é necessário instalar nenhuma dependência via `npm`. Execute os comandos usando o Node diretamente:

### Criar uma nova tarefa
```bash
node index.js add "Comprar mantimentos"
```
